Cyberforums 商务界面设计方向

方向 A（货架 IM）：① 咨询商品 ② 订单售后 ③ 售前留资 ④ 商家三栏，以及「我的订单 / 订单详情 / 售后」子页面。全部为示例数据；样式只引用 tokens.css；钩子统一为 data-mc-*。
