## 必改（不改不进前端）

1. **F1 点击区**：`.cf-link` / `.cf-textbtn` 加 padding 或 min-height，命中区 ≥24px（移动端 ≥44px 为佳）。涉及：发给商家、查看商品、重发、查看订单、再次咨询、全部 7、重试。
2. **F2 钩子**：`data-cf-*` 统一改 `data-mc-*`（设计已在做），并与 cf-frontend 核对 cooked allowlist。
3. **F3 补图**：补 ①② 的桌面亮/暗整页截图，凑齐四套。
4. **F4 页面结构**：会话页顶栏店名用 h1（或视觉隐藏 h1）；多个 nav/aside 加 aria-label 区分。

## 建议（不卡上线）

5. **S1** 时间戳改按时间段分组（同一人 5 分钟内只显示一次），去掉逐条时间。
6. **S2** 暗色卡面再提一档（surface 与 thread 拉到 ≥1.15），或暗色会话底再压暗。
7. **S3** 咨询页：询商卡已发出后，顶部商品条可收为一行或隐藏「发给商家」，避免重复。
8. **S4** 品牌感：顶栏加店铺小头像或字标，不加色块。
